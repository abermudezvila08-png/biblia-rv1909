# Biblia Desplegable · RV1909

App web autónoma (un solo archivo, sin dependencias) de estudio bíblico temático con texto Reina Valera 1909 (dominio público).

- Tres libros: Historias · Doctrina · Sabiduría
- 34 fichas temáticas (personajes, sucesos, doctrina, sabiduría) organizadas en 19 secciones
- 146 referencias con su texto RV1909 incluido
- Interfaz en español, inglés, portugués y francés (el texto bíblico permanece en español)
- Notas personales, estadísticas de lectura y progreso guardados en el dispositivo (localStorage)
- Lector de pasajes con copia al portapapeles
